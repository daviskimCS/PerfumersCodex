# Project Overview

## What it is

An open-source, public, curated aromachemical reference web app for working perfumers. A single, well-cited, beautifully presented source of truth for safety data, olfactive properties, usage guidance, and landmark uses of the aromachemicals and naturals used in modern perfumery.

## Why it exists

The current state of aromachemical reference information is fragmented and inconsistent. A working perfumer typically has 5–8 browser tabs open during a formulation session: IFRA's standards site, a supplier's product page, The Good Scents Company, Fragrantica, Basenotes, a PDF of an SDS, maybe a paper notebook. Information is scattered, often unsourced, and frequently out of date.

This project consolidates that information into one searchable, cited, modern reference — built by a working perfumer, for working perfumers.

## What makes this different

- **Citation-driven.** Every fact links to its source. No "AI-generated" or scraped-without-attribution content.
- **Curated, not aggregated.** Hand-selected materials, written-from-experience descriptions, judgment-based landmark uses. Quality over coverage.
- **Modern, polished software.** Real engineering, real polish. Most existing tools in this space are visually and functionally dated.
- **Open-source code, openly licensed data.** Built for the community, not extracted from it.

## Target users

- **Primary:** Indie perfumers working with aromachemicals at home or in small studios — both hobbyists building serious craft and small commercial brands.
- **Secondary:** Perfumery students, fragrance writers/critics, people new to aromachemicals who want a trustworthy starting point.
- **Tertiary:** Anyone curious about the chemistry behind perfume.

## What it is NOT

- Not a replacement for the actual IFRA Standards (it's a workflow reference and links to authoritative sources)
- Not a marketplace or supplier directory
- Not a Fragrantica-style "rate the perfume" platform
- Not a comprehensive database of every known aromachemical (that's a different project at a different scale)
- Not a personal formulation log in v1 (deferred to v2 — see scope doc)

## Core value proposition

> "The reference I wish existed when I sat down to work on a formula."
